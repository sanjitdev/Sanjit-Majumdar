03 / Decisions

Calls I made and what I'd reconsider.

Six decisions that shaped this build, including the one I think I got wrong.

01
Next.js 16 over plain HTML
Instead of: hand-rolled HTML + a Makefile

The MDX-to-static-export pipeline is the single biggest time saver on this site. Drafts feel like writing a blog post, not hand-authoring HTML. Worth the dependency weight because content velocity matters more than 8KB saved on the build pipeline.

02
CSS Modules over Tailwind
Instead of: Tailwind utility classes

The design system has a strong opinion about layered glass, hairline borders, gradient surfaces. CSS Modules lets me name those opinions once (`.glass-card`, `.hairline`, `.gradient-button`) and re-use them. Tailwind would have made every component read like a config file.

03
Self-hosted Plausible
Instead of: Google Analytics · Vercel Analytics

No cookies, no PII, no consent banner. Run my own instance on a $5 VPS because I didn't want to depend on the analytics vendor staying alive. Privacy is the feature; the data is the side effect.

04
Static export everywhere
Instead of: SSR / ISR for every page

100% of routes are pre-rendered at build. ISR is only for the /now ticker (30s revalidate). The cost of static is build time on every push; the benefit is zero cold-start, no DB connection, no auth flow. For a portfolio with < 50 pages, the trade-off is obvious.

05
No Sentry (deliberate)
Instead of: Sentry for runtime error tracking

No runtime = no client errors worth tracking. If something breaks on the build, the deploy fails. If something breaks at the edge, Vercel shows me. The marginal value of Sentry on a static site is below the integration tax. I would reconsider this the moment I add a single client-side interaction that writes data.

06
Dark mode in v1.5
Instead of: Shipping dark mode day one

Punted because the design system has a strong opinion about deep-dark layered glass — implementing it well requires designing it on purpose, not bolting on a `prefers-color-scheme` swap. v1 ships the Studio Fusion dark-first direction; v1.5 will add a light variant with the same layered-depth language translated up.
