Key decisions · Why these, not the alternatives

The calls I made — and
the ones I'd reconsider.

Decision · Next.js over plain HTML

I almost shipped a static site.

Next.js gives me MDX support without losing static rendering. The cost is a build pipeline; the benefit is type-checked frontmatter and component composition in content. Worth it.

Decision · CSS Modules over Tailwind

Styling scales with content density.

Tailwind is fine for many things. For a content-first site where typography does the work, plain CSS with tokens reads cleaner. Files are bigger; the result is easier to debug.

Decision · Plausible self-hosted

No third-party trackers.

I don't want analytics on this site from a vendor that sells the data. Plausible is a single JS file, no cookies, runs on my own subdomain. Five-minute install.

Decision · RSS serverless endpoint

The /now feed needs to be dynamic.

Everything else is static. /now updates weekly. The endpoint re-builds the RSS feed on update. Closed set, single function, no edge-runtime complexity.

I'd reconsider · Sentry

Defer loading Sentry until needed.

For a portfolio site, Sentry may be overkill. I have it deferred via next/script and never load it on a normal page view. Could probably drop it entirely.

Dark mode in v1.5

This whole site ships dark-first.

For the v2 visual direction, dark is the canonical mode. Light mode ships in v1.5 as a paired alternative. The reverse of the canonical Quiet Authority.
