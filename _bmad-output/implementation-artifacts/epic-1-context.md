## Goal
Stand up the Next.js 16 + Vercel scaffold with every closed design list codified in code exactly once, the cross-cutting CI harness green against a minimal homepage, and every persistent client component tested against preview environments — even those not yet mounted on a user-facing page (per elicitation pre-mortem strengthening). Every subsequent epic compiles against the closed sets in AD-13 (client components), AD-15 (shadcn scope), AD-17 (signature-canvas modes), AD-18 (design tokens), AD-19 (breakpoints), and AD-20 (accessibility floor); if E1 ships with a hole in any of these lists, E3 / E5 will hit it as a regression. This epic owns FR-1 (persistent positioning header), FR-2 (homepage hero + proof numbers), and FR-19/20/21/22 (CI performance + budget gates).
## Stories

## Requirements & Constraints
- **Stack pinning**: Next.js 16.3.6+, React 19.2, TypeScript 5.1+, Tailwind CSS 4.x via `@import "tailwindcss"` (no `tailwind.config.ts`), pnpm with committed `pnpm-lock.yaml` and `--frozen-lockfile`, Node 20.9.0 minimum in `engines`. Zod 4 and `@next/mdx` v3 pinned for downstream epics.
- **Performance budgets (CI-asserted)**: homepage LCP < 1.8s on Slow 4G mobile; total homepage transfer < 100 KB gzipped, any other route < 200 KB gzipped; Lighthouse Performance ≥ 95 mobile; total JS ≤ 50 KB gzipped on first load; CLS < 0.05 site-wide; no third-party JS on critical path; deferred scripts via `next/script strategy="lazyOnload"` only.
- **Route-level invariants (CI-asserted)**: every URL under `/`, `/work/*`, `/projects/*`, `/lab/*`, `/patterns/*`, `/now`, `/about`, `/recruiter`, `/built`, `/404` must contain (1) spine-line variant string, (2) ≥1 proof number from `{7+, 10K+, 35%, 22h, 1.2M, −68%, 7-person, 6, 8+ years}`, (3) `href="/"` or `href="https://sanjit.dev"` return path. `/built` HTML must additionally contain `data-sig-canvas-mode="layered-architecture"`.
- **Accessibility floor (CI-asserted via pa11y-ci)**: WCAG 2.1 AA; semantic landmarks (`<header role="banner">`, `<nav aria-label="Primary">`, `<main id="main">`, `<footer>`); `<SkipToContent>` first focusable; `aria-current="page"` on active nav; `aria-pressed` on filter chips; `aria-live="polite"` on `/now` ticker; `prefers-reduced-motion` honored site-wide; touch targets ≥ 44px on small breakpoint; `#FAFAFA` on `#06070B` ≈ 19:1 contrast.
- **Security**: strict CSP via `next.config.js` headers — `default-src 'self'`, `script-src 'self' 'nonce-<runtime>' https://plausible.io`, `style-src 'self'` (no `'unsafe-inline'`; SRI via `experimental.sri: { algorithm: 'sha256' }`), `img-src 'self' data:`, `connect-src 'self' https://plausible.io https://api.resend.com`, `frame-src 'self' https://*.sanjit.dev`. Nonce path explicitly rejected (incompatible with static-first paradigm).
- **Weekly content audit** workflow fails CI if any Vercel deployment in past 7 days was triggered by a content-repo commit.
## Technical Decisions
- **Paradigm**: Static-first with edge-rendered islands. Server-rendered routes by default; client JS ships only for the closed client-component set under `components/client/`. Layout is server component (no `"use client"` at layout level).
- **Project layout**: `app/` (Next.js App Router routes, including `app/layout.tsx`, `app/page.tsx`, `app/globals.css`, `app/recruiter/page.tsx` placeholder structure for later epics); `components/client/` (10 closed client components); `components/ui/` (shadcn primitives); `lib/canvas-modes.ts` (9-mode enum); `lib/design-tokens.ts` (mirror of closed token set); `proxy.ts` at project root (NOT `middleware.ts`) for the 308 redirect from `/?for=recruiter*` to `/recruiter*` preserving query params.
- **Closed client-component set (10, AD-13)**: `SignatureCanvas`, `ScrollProgress`, `CommandPalette`, `MagneticCTA`, `LayerRowHover`, `SkipToContent`, `NavCurrent`, `FilterChipGroup`, `AnalyticsBeacon`, `ErrorBeacon`. Each begins with `"use client"` and lives in `components/client/`.
- **Closed shadcn set (3, AD-15)**: exactly `Dialog`, `Toggle`, `Tooltip` plus `utils.ts` (`cn()` helper). Not a general-purpose library; reserved for downstream consumers.
- **Closed signature-canvas modes (9, AD-17)**: `dual-ring` (/, violet), `filter-graph` (/work), `section-progress` (/work/[slug]), `timeline` (/projects/[slug]), `decision-graph` (/patterns and /patterns/[slug]), `experiment-graph` (/lab and /lab/[slug], pink `--accent-3`), `activity-feed` (/now), `layered-architecture` (/built, cyan `--accent-2`), `condensed-4-node-status` (/recruiter, green `--colors.live`). No canvas on `/now/feed.xml` or `/404`. Idle `sigFlow` dash-offset 2s linear infinite, collapses under reduced-motion; `aria-hidden="true"`; `pointer-events: none`; `display: none` below `xl`.
- **Closed design-token set (57, AD-18)**: Tailwind v4 `@theme` block in `app/globals.css`; mirrored in `lib/design-tokens.ts`; categories: 21 colors, 13 typography, 9 spacing, 5 shapes, 4 shadows, 4 gradients. Three accent roles (`--accent` every page, `--accent-2` Built only, `--accent-3` Lab only) never co-occur. `--live` reserved for live/shipping/now; `--warn` reserved for counter-line. No inline hex/px outside closed set (CI lint enforces).
- **Closed responsive breakpoints (4, AD-19)**: `xl ≥ 1280px` (full nav + canvas + two-column hero on `/built`); `lg 1100–1279px` (nav links + cmdk trigger visible, no canvas); `md 900–1099px` (single-column hero, 2-up grids, cmdk hidden but openable via ⌘K); `sm < 900px` (single column, canvas fully hidden, touch targets ≥ 44px). `@media (prefers-reduced-motion: reduce)` applies at every breakpoint.
- **Closed serverless endpoints (3, AD-3, for downstream)**: `GET /api/now` (edge), `POST /api/forward-pdf` (Node.js, ≥1769 MB), `POST /api/revalidate` (edge). Adding any endpoint requires spine amendment.
## UX & Interaction Patterns
- **Hero (homepage)**: spine line verbatim ("This person builds serious software — and this website is proof."), gradient-text climax on `--font-display` clamp, four v4 proof numbers (1.2M patients served, −68% P95 latency, 22h MTTR, 6 engineers mentored) rendered at final value (no animated counters), mono labels below, positioning line in `--font-hero-spine`, magnetic CTA climax gated by `pointer:fine` AND `NOT prefers-reduced-motion`. Signature canvas mounts `mode="dual-ring"` at `xl+`, hidden below.
- **Persistent Nav**: sticky 76px tall, `backdrop-filter: blur(20px)` over `rgba(6,7,11,0.72)`; three regions — brand mark (gradient 28×28 square with cursor-style node-pulse halo + "Sanjit Majumdar" wordmark), seven nav links (Home / Work / About / Lab / Now / Built / Recruiter) with `aria-current="page"` via `<NavCurrent>`, right region (⌘K trigger with `<kbd>` hint + single `<MagneticCTA>`). Bottom edge carries 1px `<ScrollProgress>` bar in `--accent`, passive scroll listener, 100ms transition, pinned at 0% under reduced-motion. Below `lg` (1100px) nav links + cmdk trigger hide; below `md` (900px) cmdk trigger hides (palette openable via ⌘K).
- **ProofVectorCluster**: numbers in `--gradient-text` (violet → cyan → pink, 135deg) on `--font-headline-md`, mono labels below in `--font-label`.
- **CommandPalette**: `role="dialog"` `aria-modal="true"` `aria-labelledby="cmdk-title"`; focus trap inside input + list; live fuzzy filter; Esc / scrim click closes; panel 640px max, `--rounded-lg`, `--shadow-lg`; scrim `rgba(6,7,11,0.72)` with `backdrop-filter: blur(24px)`; result list `<ul role="listbox" aria-live="polite" aria-relevant="additions">` with `<li role="option" aria-selected>`; open transition collapses to 0.01ms under reduced-motion.
- **MagneticCTA**: `pointermove` translates button by 0.18× pointer offset (clamped ≤8px displacement); gated by `matchMedia('(pointer: fine)')` AND `NOT matchMedia('(prefers-reduced-motion: reduce)')`; static button fallback remains focusable with same label.
- **SkipToContent**: first focusable element on every route; `top: -100px` until `:focus`, then `top: 1rem`; touch target ≥ 44px on `sm`.
- **Footer-level "For recruiters?" link** on every page (recruiter-mode is a route, not state — `?for=recruiter` maps to SSG `/recruiter` route per amended AD-8).
- **Voice & tone**: banned phrases ("Welcome to my portfolio!", aspirational timestamps, marketing copy on side projects); required phrasings ("This person builds serious software — and this website is proof.", "Walked into the build notes anyway.", "the gap annoyed me."); numbers stay tight (`22h`, `90s`, `1.2M`, `−68%`); real em-dashes (U+2014).
- **Discipline**: `--gradient-text` only on display sizes; `--gradient-button` only on focal primary CTA; `--gradient-card` only as 1px hairline at top of cards; pure-black shadows (no chromatic); mono for structural (labels, breadcrumbs, timestamps, code blocks).
