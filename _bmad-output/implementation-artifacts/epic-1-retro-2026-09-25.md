## What Went Well

1. **Closed-set discipline held across 11 stories.** Every story introduced a closed list and none silently grew. `scripts/audit-routes.spec.mjs` (PROOF_NUMBERS verbatim lock) caught a real drift risk at the spec level.
2. **Frequent review-loopback rounds caught real defects** before they became regressions: 1-6 (motion-gate flicker), 1-7 (`aria-current` derivation), 1-9 (proxy matcher width), 1-10 (`cn()` location + Tooltip animation classes).
3. **Cross-context discipline worked**: build → step-04 self-review → fresh-context [CR] code review → orchestrator disposition. The audit-routes anomaly on story 1-11 was caught at the cross-context boundary.
4. **Deferred-work.md as institutional memory**: 22 entries with `source_spec` + `evidence` references; the canonical surface for surfacing deferred issues.
5. **Pre-published spine (AGENTS.md pitfalls + AD numbers)** let every spec re-bind closed sets with file:line anchors.

## What Didn't Go Well

1. **`app/__preview/` was unreachable from CI** — Next.js's underscore-prefix private-folder convention silently excluded every preview harness from build output. Surfaced in 1-8 review; deferred across 4 stories; resolved in 1-12 fix 4.
2. **Multiple specs referenced runtime tests that don't exist** — JSDOM/vitest harness (1-6), `pnpm typecheck`/`pnpm lint` in CI (1-1), CSP regression tests (1-2), `proxy.ts` 308-redirect regression (1-3), TooltipProvider-wrap lint rule (1-10). All deferred to a future CI-hardening story.
3. **`pnpm build` emits a pre-existing `@theme` deprecation warning** from 1-5 on every build. Doesn't fail CI but compounds. Newly filed in deferred-work.md.
4. **`audit-routes.spec.mjs` was the only verbatim closed-set lock** in the project — `CANVAS_MODES`, `NAV_LINKS`, `components/client/` count, `components/ui/` count, and the audit-script mount-point selectors all lacked parallel locks. Fix 1 of 1-12 added one (the mount-points); others still pending.
5. **Story 1-11 had no pre-existing spec doc** — drafted via `bmad-create-story` flow as part of the build agent's step-01. Worked because the epic AC list was self-sufficient, but a smell.
6. **Deferred amendments #14, #15, #16** are parked in `sprint-status.yaml` project-notes but their partial-mitigation stories are deep in the backlog. No enforced tracking that mitigations land before the deferred amendments become load-bearing.

## Cross-Cutting Patterns

- **3 of 5 review-loopback rounds found spec defects.** The spec template's `Tasks & Acceptance` is not strict enough by itself; reviewers had to enumerate runtime contracts.
- **Trade-off between "spec-owns-the-contract" vs "audit-script-owns-the-contract"** surfaced in 1-11 (gradient-text span-split broke the audit's substring match). Resolution: structural component-text check via `extractComponentText` mount-point selectors.
