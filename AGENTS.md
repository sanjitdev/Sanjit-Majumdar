### Invariants

1. **Static-first** — every public route is SSG or ISR. Client JS ships only inside the closed set above (AD-13).
2. **No SPA shell, no global client provider** — no layout-level `"use client"` boundary (AD-13).
3. **Additive schema** — every content frontmatter field except `title` is optional; unknown keys preserved via Zod `.passthrough()` on `entry.meta` (AD-5).
4. **Build fails on malformed published frontmatter** — `Zod.safeParse()` must succeed for every `status: published` entry; `draft` entries may be malformed and are excluded from build output (AD-5).
5. **Content edits never trigger a build** — only `revalidateTag(tag, 'max')` via webhook (AD-1, AD-9).
6. **Recruiter-mode is a route, not a client state** — `app/recruiter/page.tsx` is an SSG route. `?for=recruiter` URL param maps to this route (canonical share form for the forward artifact), but there is no `<RecruiterModeToggle>` component, no `RecruiterModeProvider`, and no `localStorage` flag (AD-8).
7. **Forward flow is route-level** — canonical share URL is `https://sanjit.dev/recruiter?forward=1&case=<slug>`; PDF download is a link to `/api/forward-pdf?case=<slug>`; on Puppeteer failure the link mutates into "Print via browser" that calls `window.print()` on the `/recruiter` route. No modal (AD-14).
8. **Pattern citation walker walks only `status: published` entries** — drafts don't break the build (AD-4).
9. **Route-level invariant in CI** — every public route contains spine-line variant + ≥1 proof number from `{7+, 10K+, 35%, 22h, 1.2M, −68%, 7-person, 6, 8+ years}` + return path `href="/"`. `/built` additionally asserts the `layered-architecture` signature-canvas mode id (AD-12).
10. **CSP via SRI** — `experimental.sri` in `next.config.js`; nonce path is explicitly rejected (AD-11).
11. **Live architecture diagram** — the "How this site is built" page renders an MDX component that reads BOTH `architecture-diagrams.md` AND `DESIGN.md.components.sig-canvas.modes` at build time. Co-sources for the `layered architecture` mode; diagram never drifts from either (AD-6).
12. **Snapshot write-back ownership** — phone-edits write to KV only; a GitHub Action in `sanjit-content` runs every 15 min, reads KV, and commits `now-snapshot.json`. No serverless function pushes to the content repo (AD-10).
13. **Signature-canvas mode is route-determined** — each route renders exactly one of the 9 closed modes; no route renders two. The recruiter route uses the `accent-live` (green) accent; every other route uses `--accent` (violet) or its page-specific accent (Built = `--accent-2`, Lab = `--accent-3`). Idle animation is the only animation; collapses under `prefers-reduced-motion` (AD-17).
14. **Design tokens are closed** — colors, typography, spacing, shapes, shadows/gradients live as Tailwind v4 `@theme` custom properties in `app/globals.css`. Inline hex/px values outside the closed set are a review failure. Reference via `var(--token-name)` (AD-18).
15. **Responsive breakpoints are closed** — 4-way ladder (`xl` / `lg` / `md` / `sm`). The signature-canvas slot is `display: none` below `xl`. Mobile layout reflows the freed 240×240 + 24px right margin (AD-19).
16. **Accessibility floor (WCAG 2.1 AA)** — semantic landmarks, skip-to-content as first focusable element, `role="dialog" aria-modal="true" aria-labelledby` on command palette, `aria-current="page"` on active nav link, `aria-hidden="true"` on signature canvas and hairlines, `aria-live="polite"` on the NOW ticker list and on the `/recruiter?forward=1&case=<slug>` recommended-case-study callout, `prefers-reduced-motion` honored site-wide, `pointer:fine AND NOT prefers-reduced-motion` gates magnetic CTA, touch targets ≥ 44px on mobile. ### Conventions that differ from defaults

- **File naming:** kebab-case (`wellbook.mdx`, `canonical-model.mdx`). Slugs derive from filenames, overridable via `slug` frontmatter.
- **Component naming:** PascalCase. Client components: `"use client"` at file top is the source of truth. Zod schemas end in `Schema` (`CaseStudySchema`).
- **Middleware/proxy:** `proxy.ts` at project root (Next 16; `middleware.ts` is deprecated). Used for nothing CSP-related (per AD-11 — nonce path rejected).
- **State mutations:** through serverless functions only; clients POST, never write to Upstash Redis directly.
- **Auth:** none in v1. Contact form uses Cloudflare Turnstile token + honeypot.
- **Config:** Vercel env vars only; no `.env` files committed; no secrets in content.
- **Logging:** structured JSON, every serverless function emits `{ request_id, route, duration_ms, status }`. `request_id` from `crypto.randomUUID()` server-side; GitHub Actions uses the run ID.
- **Errors from serverless:** shape is `{ error: { code, message, request_id } }`.
- **Bundler:** Turbopack default (`next build` and `next dev` both use it in Next 16).
- **Motion discipline (v4):** every animation honors `prefers-reduced-motion: reduce` (collapse to 0.01ms or disable). Pointer-driven motion (magnetic CTA, hover lift on cards) is additionally gated on `pointer:fine AND NOT prefers-reduced-motion`. The signature canvas's idle animation is the only animation on first paint; the command palette's open transition, the scroll-progress bar, the filter-chip aria-pressed swap, and the layer-row hover-sync all collapse under reduced motion (AD-13, AD-16, AD-20).
- **Visual tokens (v4):** Tailwind v4 `@theme` block in `app/globals.css` is the closed source of truth for colors, typography, spacing, shapes, and shadows. Components reference tokens via `var(--token-name)`; inline hex/px values outside the closed set are a review failure (AD-18).

## Known pitfalls

1. **Vercel KV was retired December 2024.** Use **Upstash Redis via Vercel Marketplace**. Same Redis API surface; the spine's AD-2 namespace model carries over unchanged. New projects cannot create Vercel KV stores.

2. **Next.js 14 is two majors stale and has live CVEs** (CVE-2025-66478 CVSS 10.0 in RSC, plus CVE-2025-55184 / CVE-2025-55183). Pin Next 16.3.6+. Do not downgrade.

3. **`revalidateTag(tag)` single-argument form is deprecated in Next 16.** Use `revalidateTag(tag, 'max')` for stale-while-revalidate, or `revalidateTag(tag, { expire: 0 })` for webhook-triggered immediate expiration.

4. **`middleware.ts` was renamed to `proxy.ts` in Next 16.** New code uses `proxy.ts` at project root. `middleware.ts` still works but is deprecated; spine convention is `proxy.ts`.

5. **Puppeteer cannot run on edge.** `POST /api/forward-pdf` is `runtime = 'nodejs'` with `maxDuration = 60` and ≥ 1769 MB memory allocated. `@sparticuz/chromium` requires a Linux Node environment; the edge runtime cannot host it.

6. **CSP `'unsafe-inline'` on `style-src` is NOT required** — Next 16 with `experimental.sri: { algorithm: 'sha256' }` produces hash-based integrity for built CSS, so the nonce/`'unsafe-inline'` path is unnecessary and is explicitly rejected (forces dynamic rendering, conflicts with AD-13).

7. **Tailwind v4 uses CSS-first config.** No `tailwind.config.ts` file. Configuration lives in `app/globals.css` via `@theme` blocks. shadcn/ui's `cn()` helper and the `@tailwindcss/vite` plugin are still the integration points.

8. **Contentlayer is unmaintained.** Use raw `@next/mdx` + Zod, or migrate to Velite. Do not add contentlayer.

9. **GitHub Actions webhook coverage:** the Action in `sanjit-content` must listen to `push`, `delete`, AND force-push events. Missing force-push coverage breaks AD-1's freshness guarantee.

10. **`@next/mdx` parses frontmatter** as raw text — pair with `gray-matter` or Velite, NOT contentlayer. AD-5's `.passthrough()` requires Zod 4, not Zod 3.

11. **The spine line is fixed copy** — never edit. Position: hero of homepage in recruiter-mode, top of forward artifact, persistent positioning header variant on every public page. Source: `docs/idea.md` brain dump, locked in SPEC.md Why + PRD §3.

12. **shadcn/ui scope** (AD-15) — only `Dialog`, `Toggle`, `Tooltip`. Do not pull in shadcn's full registry. Adding a new primitive requires updating the spine.

13. **Visual-design AI skills are reviewers, not authors** (AD-16) — UI/UX critique skills ("ui ux pro max", "impeccable" class) may run, but their output goes to `reviews/design-review-{slug}.md` and is review notes, not spine amendments. Any recommendation that would (a) add client JS beyond the closed set in AD-13, (b) change the spine line copy, (c) reorder the `/recruiter` route-level forward flow's button hierarchy (AD-14), (d) break AD-12's route-level invariant (including the `/built` `layered-architecture` assertion), (e) introduce motion that ignores `prefers-reduced-motion` or `pointer:fine`, or (f) introduce a visual token outside the closed set in AD-18 is logged as a deferred item and not adopted.

14. **Deferred spine amendment — AD-4 move-id validation.** `epics.md` "Cascading Failure Surface #1" notes that AD-4 fails the build on an unpublished cited slug, but does NOT validate the `pattern_moves: { "<slug>": <N> }` override against the published pattern's heading-ID set. A case-study citing `pattern_moves: { "canonical-model": 3 }` where move-3 isn't authored silently renders as a broken `#move-3` anchor (CI route-invariant passes because the link text is present). **Status: deferred per AD-16. NOT adopted yet.** To adopt: extend AD-4 with build-time validation of `pattern_moves` overrides against the published heading-ID set. Source: `epics.md` lines 164–168.

15. **Deferred spine amendment — AD-6 + AD-12 7-layer drift.** `epics.md` "Cascading Failure Surface #2" notes that AD-12's `data-sig-canvas-mode="layered-architecture"` assertion does NOT check that the 7-layer enumeration matches across `architecture-diagrams.md`, the big-version SVG, the signature-canvas small-version, and the layer-table rows. NOT adopted yet.** To adopt: extend AD-12 (or add AD-21) with a build-time consistency check that the four representations enumerate the same 7 layers in the same order. Source: `epics.md` lines 170–174; partial mitigation in `epics.md` Story 5b.3.

16. **Deferred spine amendment — AD-7 + AD-14 mobile-touch fallback.** `epics.md` "Cascading Failure Surface #3" notes that AD-7 + amended AD-14 specify `window.print()` fallback when Puppeteer fails; on mobile Safari `window.print()` is blocked programmatically, so touch devices get no fallback affordance. **Status: deferred per AD-16. NOT adopted yet.** To adopt: amend AD-7 / AD-14 so the "Copy URL" link is always visible regardless of Puppeteer success, with `window.print()` as a desktop-only secondary affordance when Puppeteer fails. Source: `epics.md` lines 176–180; partial mitigation in `epics.md` Story 4.4 ("Implement mobile-touch-resilient fallback").

## Two-repo topology

This is the **code repo** (`sanjit-portfolio`). Content lives in a separate repo (`sanjit-content`) — the build does a shallow `git clone` of it at build time, and a GitHub Action in `sanjit-content` calls `POST /api/revalidate` on push/delete/force-push. AGENTS.md lives only in this repo. **Mirror scope (binding):** the content-side `sanjit-content/AGENTS.md` mirrors ONLY the rules the content repo can honor — it does NOT import AD-13's closed client-component set (the content repo has no Next.js runtime), AD-17's signature-canvas mode list (no canvas there), AD-18's design tokens (no `@theme` block), AD-19's breakpoints (no Tailwind v4 CSS), or AD-20's accessibility floor (the content repo renders plain Markdown, served as MDX to the code repo at build time). What the content-side mirror DOES carry: AD-1 (webhook coverage), AD-2 (KV namespace ownership — content-side perspective is "never write KV from a content commit"), AD-5 (additive schema, `status: published` gating), AD-9 (build does not run on content edits), AD-10 (snapshot commit cadence — 15 min, KV-derived only), the closed frontmatter shape (additive, Zod 4 `.partial + .passthrough`), and the closed ISR tag enumeration (`<type>:<slug>` + bare `now`/`cv`). Everything else is code-side only.
